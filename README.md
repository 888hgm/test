# 飞书多维表格仪表盘柱状图插件

版本：0.1.2。

支持选择多个状态或选项字段作为横轴：每个字段显示一根柱，柱内按照该字段的选项统计记录数。例如，选择“项目策划、设计评审、开发实施、测试验收”后，得到四根柱，每根柱分别显示“已完成、进行中、未开始”的分布。

支持普通堆积、百分比堆积和分组柱状图；百分比模式下，每根柱独立换算为 100%。相同选项名称使用相同颜色；空值归入“未填写”。多选字段的实际返回格式尚需在真实飞书环境中验证，建议先使用单选状态字段。

## 上传 GitHub，再交给飞书

详细操作见 [UPLOAD_TO_GITHUB.md](./UPLOAD_TO_GITHUB.md)。

1. 解压源码包，在 GitHub 创建一个 **Public（公开）** 仓库。
2. 上传解压目录里面的文件和文件夹。仓库首页应直接看到 `package.json`、`src` 和 `dist`，不要再套一层文件夹，也不要只上传 ZIP。
3. 提交后复制仓库主页地址，例如 `https://github.com/your-name/feishu-chart-plugin`。
4. 在飞书多维表格开发者中心，选择“插件 → 仪表盘插件”，将仓库主页地址填写到“插件代码 Github 地址”。填写基础信息后，按照页面提示保存或发布。
5. 飞书完成代码读取、构建及审核等步骤后，在发布范围内的多维表格仪表盘插件入口添加组件。
6. 在组件配置里选择数据表和横轴字段，检查预览，点击“添加到仪表盘”。之后修改配置时点击“保存配置”。

“插件代码 Github 地址”填写的是源码仓库主页。若走仪表盘内“添加自定义插件 → 服务地址”的另一种方式，则需要先自行部署 HTTPS 网站，再填写网站地址。

本仓库参考[飞书官方仪表盘模板](https://github.com/Lark-Base-Team/dashboard-html-template)，在 `package.json` 中设置 `"output": "dist"`。包含源码、依赖锁定文件和预构建产物；飞书是否通过审核以及真实数据下的完整运行结果，需要以平台验证为准。

## 本地开发与构建

需要 Node.js 22.12 或更高版本，建议使用 Node.js 24 LTS。

```sh
npm ci
npm run dev
```

打开终端提示的本地地址。独立打开时使用虚构示例数据，配置保存到当前浏览器；在飞书 iframe 中打开时连接飞书 SDK。连接失败会显示错误。

```sh
npm test
npm run build
npm run preview
```

Windows PowerShell 若提示禁止运行 `npm.ps1`，把命令中的 `npm` 换成 `npm.cmd`。

`npm run build` 先进行 TypeScript 检查，再生成 `dist`。通过 GitHub 网页上传时，请一并上传包内的 `dist`。修改源码后应重新构建并更新 `dist`。

## 功能与使用约定

- 多字段横轴：勾选字段、调整顺序、按每个字段的选项计数，支持逐柱百分比。
- 图表外观：标题、配色、渐变、图例、数据标签、坐标轴、网格线、横向显示和 PNG 导出。
- 单字段分类模式：可按字段值分组，支持计数及数值汇总。
- 多数据表模式：多字段横轴要求各表选中的字段名称和顺序一致，再合并到对应柱中。
- “字段统计次数”会将每条记录在每个选中字段各统计一次，不能作为去重记录数。
- 首次创建不调用宿主禁止使用的 `getConfig()`；创建界面提供顶部和底部的“添加到仪表盘”按钮。

数据范围当前为全部数据；界面中的关键词筛选作用于汇总后的分类名称。原生条件筛选器、指定视图和原生筛选联动尚未实现。数值字段仅识别 SDK 的 `FieldType.Number`；公式等字段需进一步适配。PNG 导出包含图表画布。

## 验证范围

模型及仪表盘初始化逻辑有 16 项自动化测试。浏览器验证覆盖示例数据交互，以及模拟飞书 Create 状态下的初始化、选字段、预览和保存。模拟测试不能替代真实飞书联调。

多字段统计使用 SDK 的组合分组计数，再转换为各字段的选项计数。真实飞书的分组字段数量限制、返回规模和复杂字段格式仍需验证；若平台截断分组结果，可能影响统计准确性。

## 目录

```text
package.json             # 构建脚本、依赖和 output: dist
package-lock.json        # 锁定依赖版本
index.html
tsconfig.json
src/                     # 配置界面、图表、数据模型、飞书 SDK 适配
tests/                   # 模型和初始化测试
dist/                    # 已构建网站，可作为静态托管内容
UPLOAD_TO_GITHUB.md      # GitHub 上传及飞书填写步骤
```

仓库无需填写飞书 App Secret、GitHub Token 或腾讯云密钥。运行时通过飞书仪表盘 SDK 获取宿主授权范围内的数据。
